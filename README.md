# NEUST Civil Engineering Department

Official course-material website repository for NEUST Civil Engineering Department.

## COMPRE 1

The COMPRE 1 recitation viewer (2017 and 2018 sets) belongs in `compre-1/`.

The viewer package is available in the ChatGPT conversation as `neust-compre1-site.zip`. Extract it and upload its `index.html` and `pages/` directory **inside** `compre-1/` to retain the image paths.

## GitHub Pages
